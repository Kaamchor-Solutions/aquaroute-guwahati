Use this data

Everything here is open and free. Point an AI assistant at the MCP address, or call the JSON routes directly. Reports are community-submitted and unverified; they last 12 hours live and are kept as history without photos or any personal data.

MCP server (Streamable HTTP, no key). Works in Claude, Claude Code, Cursor, VS Code and any MCP client. 60 requests per minute per IP.
